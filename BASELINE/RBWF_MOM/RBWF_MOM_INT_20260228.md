# รายงานการประชุม (ภายใน)

**ประเภท**: ประชุมภายในทีม (สรุปมติหลังประชุมลูกค้า)  
**ครั้งที่**: ภายใน 4/2026  
**ชื่อระบบงาน[TH]**: ระบบบริหารงานธุรกิจจัดจำหน่ายวัสดุก่อสร้างและกระเบื้องครบวงจร  
**ชื่อระบบงาน[EN]**: Rabbit Workflow System (RBWF)  
**วันที่ประชุม:** 28 กุมภาพันธ์ พ.ศ. 2569  
**สถานที่ประชุม:** ห้องทำงานโครงการ บริษัท ซิมโฟร์ซอฟท์ จำกัด  
**เริ่มประชุมเวลา:** 13:30 น.

---

### ผู้เข้าร่วมประชุม:

1. นางสาวปวริศา จันทรสถาพร (Project Manager)
2. นายวีระ เนียมโภคะ (System Analyst and Team Leader)
3. นายปริญญา พงษ์ดนตรี (Designer and Programmer)
4. นายประกาศิต ทองนอก (Tester)

ผู้แทนลูกค้าไม่ได้เข้าร่วม (ประชุมภายในเท่านั้น)

---

### วาระที่ 1: เรื่องที่ประธานแจ้งให้ที่ประชุมทราบ

- **วัตถุประสงค์:** ปิดมติจากประชุมลูกค้าวันที่ 27 กุมภาพันธ์ พ.ศ. 2569 ที่อนุมัติ SRS v1.0 และเก็บ PSR ที่ลงนามแล้วในคลังโครงการ

---

### วาระที่ 2: เรื่องเสนอเพื่อพิจารณา

**เรื่องที่ 2.1 งานหลังอนุมัติ SRS**

- **รายละเอียด:** Baseline ความต้องการล็อกแล้ว การออกแบบ SDD ต้องตาม REQ ที่อนุมัติ
- **มติที่ประชุม:** AN เดินหน้า SDD ให้ทันทวนสอบต้นเดือนมีนาคม PR พัฒนาโมดูล PO และงานช่างต่อจากสต็อก

**เรื่องที่ 2.2 ข้อเสนอกำไรขั้นต้นจากลูกค้า**

- **รายละเอียด:** ลูกค้ารับทราบว่าต้องยื่น CR
- **มติที่ประชุม:** AN เตรียมร่าง RBWF-CR สำหรับเดือนมีนาคม ประเมินผลกระทบ man-day โดยไม่เพิ่มงบ

**เรื่องที่ 2.3 ปิด issue เทคนิคเดือนกุมภาพันธ์**

- **รายละเอียด:** ISS-003 และ ISS-004 ปิดแล้วใน CRR
- **มติที่ประชุม:** TESTER เก็บเคส regression ของ Redis และ Sorting ไว้ในชุด TP
