# รายงานการประชุม (ภายนอก)

**ประเภท**: ประชุมร่วมลูกค้า  
**ครั้งที่**: 2/2026  
**ชื่อระบบงาน[TH]**: ระบบบริหารงานธุรกิจจัดจำหน่ายวัสดุก่อสร้างและกระเบื้องครบวงจร  
**ชื่อระบบงาน[EN]**: Rabbit Workflow System (RBWF)  
**วันที่ประชุม:** 27 กุมภาพันธ์ พ.ศ. 2569  
**สถานที่ประชุม:** ห้องประชุม บริษัท ซิมโฟร์ซอฟท์ จำกัด / Online  
**เริ่มประชุมเวลา:** 10:00 น.

---

### ผู้เข้าร่วมประชุม:

1. นางษมาภรณ์ พงษ์ดนตรี (ผู้มีอำนาจลงนาม / ผู้แทนลูกค้า บริษัท ซิมโฟร์ซอฟท์ จำกัด)
2. นางสาวปวริศา จันทรสถาพร (Project Manager)
3. นายวีระ เนียมโภคะ (System Analyst and Team Leader)
4. นายปริญญา พงษ์ดนตรี (Designer and Programmer)
5. นายประกาศิต ทองนอก (Tester)

---

### วาระที่ 1: เรื่องที่ประธานแจ้งให้ที่ประชุมทราบ

- **วัตถุประสงค์:** รายงานความคืบหน้างานพัฒนาระบบหลักเดือนแรก ตามแผน Task 2 (01 กุมภาพันธ์ – 15 เมษายน พ.ศ. 2569) และยืนยันเอกสาร SRS ที่ผ่าน Validation เมื่อวันที่ 5 กุมภาพันธ์ พ.ศ. 2569 และการทวนสอบภายในเมื่อวันที่ 15 กุมภาพันธ์ พ.ศ. 2569

---

### วาระที่ 2: เรื่องเสนอเพื่อพิจารณา

**เรื่องที่ 2.1 ความคืบหน้าโมดูลคลังสินค้าและใบเสนอราคา**

- **รายละเอียด:** PR สาธิตโครงสร้าง MySQL และการบันทึกรับเข้า-จ่ายออกสต็อก รวมถึงการดึงยอดคงเหลือไปสร้างใบเสนอราคา REST API ทำงานบน Docker Compose ตามเอกสาร IE
- **มติที่ประชุม:** ลูกค้าพอใจแนวทางบันทึกสต็อกและขอให้คงการแจ้งเตือนสินค้าขั้นต่ำ (REQ-STK-04) ในรอบพัฒนาถัดไป

**เรื่องที่ 2.2 การอนุมัติเอกสารความต้องการซอฟต์แวร์ (SRS v1.0)**

- **รายละเอียด:** AN สรุปข้อกำหนดที่ผ่าน Validation แล้ว ไม่มี REQ-STK-03 และมีข้อกำหนด NFR ด้านความปลอดภัย JWT/RBAC
- **มติที่ประชุม:** อนุมัติ SRS v1.0 เป็น baseline ความต้องการ

**เรื่องที่ 2.3 ประเด็นเทคนิค Redis และสิทธิ์ RBAC**

- **รายละเอียด:** ทีมแจ้งว่าปรับ Max Open Connections หลังพบ Connection Pool เต็มระหว่างทดสอบภายใน (ISS-003) และแยก JWT/RBAC Middleware ตาม SDD ที่กำลังร่าง
- **มติที่ประชุม:** รับทราบแนวทางแก้ไข และให้รายงานผลใน PSR กุมภาพันธ์

---
