# เอกสาร ยืนยันการทดสอบการยอมรับจากผู้ใช้ (USER ACCEPTANCE TEST DOCUMENT - UAT)

**ชื่อระบบงาน[TH]**: ระบบบริหารจัดการเวิร์กโฟลว์ สต็อกสินค้า และคำสั่งซื้อกระเบื้อง  
**ชื่อระบบงาน[EN]**: Rabbit Workflow System (RBWF)  
**เวอร์ชัน**: 1.0  
**จัดทำโดย**: นางสาวปวริศา จันทรสถาพร (PM)  
**วันที่อนุมัติเอกสาร**: 20 พฤษภาคม พ.ศ. 2569

## 1. วัตถุประสงค์ (Purpose)

เอกสารนี้จัดทำขึ้นเพื่อบันทึกผลการทดสอบการใช้งานจริง (User Acceptance Test) ของระบบ **Rabbit Workflow (RBWF)** โดยผู้แทนจาก **บริษัท ซิมโฟร์ซอฟท์ จำกัด** เพื่อยืนยันว่าระบบทำงานตรงตามขอบเขตงาน (SOW) และความต้องการของธุรกิจก่อนการลงนามรับมอบงาน

---

## 2. รายการการทดสอบและผลการยอมรับ (UAT Acceptance Checklist)

| No | รายการทดสอบฟังก์ชันงาน | ผลการทดสอบผู้ใช้ | สถานะอนุมัติ |
|---|---|---|---|
| 1 | ทดสอบการจัดการสต็อกกระเบื้อง การรับเข้า-จ่ายออก และเตือน Stock Alert | ทำงานถูกต้อง ข้อมูลตรงตามคลัง | **ACCEPTED** |
| 2 | ทดสอบสูตรการตัดแปรรูปกระเบื้อง (Edging / Cutting recipe) | ตัดสต็อกวัตถุดิบและคำนวณถูกต้อง | **ACCEPTED** |
| 3 | ทดสอบการออกใบเสนอราคา (Quotation) การคำนวณกำไร และพิมพ์ PDF | เอกสารสวยงาม คำนวณกำไรถูกต้อง | **ACCEPTED** |
| 4 | ทดสอบการเปิดใบสั่งซื้อ (PO) ส่ง Supplier และรับสินค้าเข้าคลัง | ใช้งานสะดวก สามารถอัปโหลดรูปภาพได้ | **ACCEPTED** |
| 5 | ทดสอบการสั่งงานช่าง (Worker Jobs) และแสดงคิว Queue Display บน TV | Realtime เรียลไทม์ตรงตามเวิร์กโฟลว์ | **ACCEPTED** |
| 6 | ทดสอบสมุดบัญชีเงินสด (Cash Ledger) และการบันทึกค่าใช้จ่าย/เงินเดือน | ยอดรวมและรายงานตรงตามการเงิน | **ACCEPTED** |
| 7 | ทดสอบการสิทธิ์ผู้ใช้งาน (RBAC) และระบบรักษาความปลอดภัย | กำหนดสิทธิ์เมนูและ API ได้ตามบทบาท | **ACCEPTED** |

---

## 3. สรุปผลการทดสอบการยอมรับ (UAT Sign-off Summary)

ผู้ว่าจ้าง/ลูกค้า **บริษัท ซิมโฟร์ซอฟท์ จำกัด** ได้ทำการทดสอบระบบงาน Rabbit Workflow (RBWF) ครบถ้วนทุกฟังก์ชัน และขอรับรองว่าระบบซอฟต์แวร์มีความถูกต้อง สมบูรณ์ และพร้อมสำหรับการใช้งานจริง
