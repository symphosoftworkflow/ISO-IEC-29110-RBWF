# ชี้แจงซอฟต์แวร์ที่ส่งมอบในงวดที่ 2 (Talking Points)

ใช้ตอบคำถามว่า “งวดที่ 2 ส่งซอฟต์แวร์ส่วนไหนบ้าง” โดยอ้าง [RBWF_VLD_20260327](RBWF_VLD_20260327.md), [RBWF_MOM_EXT_20260327](../RBWF_MOM/RBWF_MOM_EXT_20260327.md), [RBWF_PSR_20260327](../RBWF_PSR/RBWF_PSR_20260327.md), SOW ข้อ 5 และ PMP §4

## ประโยคหลัก

ซอฟต์แวร์ในงวดที่ 2 คือ **build หลักบน Staging** ที่สาธิตได้และเชื่อมข้อมูลระหว่างโมดูลแล้ว ตามเกณฑ์ชำระเงินใน SOW — **ไม่ใช่**การยอมรับขั้นสุดท้ายหลัง UAT และไม่ใช่ระบบพร้อมใช้งานสมบูรณ์ (อยู่ที่งวดที่ 3 / Final วันที่ 29 พฤษภาคม พ.ศ. 2569)

## เปรียบเทียบงวด

| | งวดที่ 2 (27 มี.ค. 2569) | งวดที่ 3 / Final (29 พ.ค. 2569) |
|---|---|---|
| ความหมายตามสัญญา | Milestone ชำระเงิน: ซอฟต์แวร์หลัก + การเชื่อมโยงข้อมูล + SDD | ระบบพร้อมใช้งานสมบูรณ์ + ทดสอบ + คู่มือ |
| สภาพแวดล้อม | Staging: workflowv2.rabbittile.com | Production / รับมอบขั้นสุดท้าย |
| ความสมบูรณ์พัฒนา | ประมาณ 75% ของ Task 2 (งานต่อถึง 15 เม.ย.) | 100% + ผ่าน UAT |
| UAT | ยังไม่เริ่ม (PMP เริ่ม 1 พ.ค.) | ปิดแล้ว (01–20 พ.ค.) |

## สิ่งที่ส่งมอบในงวดที่ 2

**เอกสาร**

- เอกสารการออกแบบซอฟต์แวร์ (SDD) ที่ผ่านทวนสอบและ Validation วันที่ 10 มีนาคม พ.ศ. 2569

**ซอฟต์แวร์ (Staging — API Backend + Frontend)** สาธิตและรับมอบเป็นซอฟต์แวร์หลัก ครอบคลุมอย่างน้อย

1. **สต็อก / คลัง** (SOW 3.1) — จัดการสินค้า รับ-จ่าย/ปรับยอด
2. **งานขาย** (SOW 3.2) — RFQ / ใบเสนอราคา / PDF (รวมขอบเขต CR-01 Profit Analysis ใน REQ-QTO-02)
3. **งานช่าง / คิว** (SOW 3.4) — มอบหมายงานช่าง / คิวเตรียมสินค้า
4. **การเงิน** (SOW 3.5) — ฟังก์ชันหลักบน Staging ตามที่สาธิต

**การเชื่อมโยงข้อมูล** — โมดูลทำงานบนสแตกเดียว (Go API + Svelte + MySQL/Redis) ไม่ใช่ระบบแยกหลายชุด

**สถานะที่ลูกค้ารับทราบตอนลงนาม** (MOM EXT 20260327 เรื่อง 2.2)

- พัฒนาหลักยังไม่ปิด (~25% เหลือถึง 15 เมษายน พ.ศ. 2569 ตาม PMP)
- System Testing เริ่ม 16 เมษายน; UAT 01–20 พฤษภาคม — **ไม่อยู่ในขอบเขตการรับมอบงวดที่ 2**

## สิ่งที่ไม่ได้ส่งในงวดที่ 2

- ไม่ใช่ Production final / ไม่ใช่ “ระบบเสร็จสมบูรณ์”
- ไม่มีชุดผล TP / TR / UAT แบบปิดโครงการ
- ไม่มี SUD / MA / การอบรม (อยู่งวดที่ 3)
- ไม่รับประกันว่าครบทุก REQ ย่อยใน SRS 100% ณ วันนั้น — รับในฐานะซอฟต์แวร์หลักที่สาธิตได้บน Staging ตามเกณฑ์ SOW

## หลักฐานอ้างอิง

1. SOW ข้อ 5 — คำต่างกันระหว่างงวด 2 (“ซอฟต์แวร์หลัก”) กับงวด 3 (“พร้อมใช้งานสมบูรณ์”)
2. PMP §4 — วันส่งมอบตาม SOW เป็นเกณฑ์ชำระเงิน; แผนพัฒนา/ทดสอบต่อเนื่อง
3. MOM EXT 20260327 เรื่อง 2.2 — สาธิตโมดูล + มติรับทราบพัฒนาต่อถึงกลางเมษายน
4. PSR 20260327 — ความคืบหน้าพัฒนาประมาณ 75%
5. RBWF_VLD_FINAL_20260529 / RBWF_VLD_20260529 — จุดส่งมอบระบบเสร็จสมบูรณ์
