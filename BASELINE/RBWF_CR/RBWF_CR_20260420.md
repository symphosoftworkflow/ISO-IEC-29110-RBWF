# แบบฟอร์มคำขอแก้ไขเปลี่ยนแปลง (CHANGE REQUEST - CR)

**รหัสเอกสาร**: RBWF-CR-02  
**ชื่อระบบงาน**: Rabbit Workflow System (RBWF)  
**วันที่ยื่นคำขอ**: 20 เมษายน พ.ศ. 2569  
**ผู้ยื่นคำขอ**: ฝ่ายจัดส่ง / นายประกาศิต ทองนอก (TESTER)  

---

## 1. รายละเอียดการขอเปลี่ยนแปลง (Change Request Details)

- **ความต้องการ**: เพิ่มหน้าจอแสดงผลคิวงานจัดส่งสินค้า (Queue Display Page) และระบบการสื่อสารผ่าน WebSocket Real-time สำหรับเปิดบนหน้าจอ TV คลังสินค้า
- **เหตุผลความจำเป็น**: เพื่อให้ช่างและพนักงานขับรถขนส่งเห็นคิวเตรียมกระเบื้องได้ชัดเจน ลดข้อผิดพลาดในการจัดสินค้าผิดคิว

---

## 2. การวิเคราะห์ผลกระทบ (Impact Analysis)

- **ผลกระทบต่อซอร์สโค้ด**: เพิ่ม `handlers/ws.go`, `dn_prepare_queue.go` และ `QueueDisplayPage.svelte`
- **ผลกระทบต่อระยะเวลา (Schedule)**: เพิ่มเวลาพัฒนา 5 วัน (บริหารภายในช่วงทดสอบ) ไม่กระทบวันส่งมอบงาน
- **ผลกระทบต่องบประมาณ (Cost)**: ไม่มีค่าใช้จ่ายเพิ่มเติม
