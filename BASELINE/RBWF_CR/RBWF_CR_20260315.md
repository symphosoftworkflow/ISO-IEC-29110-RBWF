# แบบฟอร์มคำขอแก้ไขเปลี่ยนแปลง (CHANGE REQUEST - CR)

**รหัสเอกสาร**: RBWF-CR-01  
**ชื่อระบบงาน**: Rabbit Workflow System (RBWF)  
**วันที่ยื่นคำขอ**: 15 มีนาคม พ.ศ. 2569  
**ผู้ยื่นคำขอ**: ทีมขาย / นายวีระ เนียมโภคะ (TL, AN)  

---

## 1. รายละเอียดการขอเปลี่ยนแปลง (Change Request Details)

- **ความต้องการ**: เพิ่มฟังก์ชันการคำนวณกำไรขั้นต้น (Profit Margin Analysis) และการวิเคราะห์ต้นทุนสินค้าในหน้าจอออกใบเสนอราคา (Quotation Management)
- **เหตุผลความจำเป็น**: เพื่อให้พนักงานขายทราบกำไรขั้นต้นในระหว่างการเสนอส่วนลดแก่ลูกค้า ป้องกันการขายขาดทุน

---

## 2. การวิเคราะห์ผลกระทบ (Impact Analysis)

- **ผลกระทบต่อซอร์สโค้ด**: เพิ่ม API Endpoint `quotation_profit.go` และปรับปรุง UI `QuotationManagement.svelte`
- **ผลกระทบต่อระยะเวลา (Schedule)**: เพิ่มเวลาพัฒนา 3 วัน (ซ้อนอยู่ในช่วงพัฒนาหลัก) ไม่กระทบวันส่งมอบโครงการ
- **ผลกระทบต่องบประมาณ (Cost)**: ไม่มีค่าใช้จ่ายเพิ่มเติม
